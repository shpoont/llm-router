# Deliverables

Use this folder when useful for files prepared for use or handover, such as
reports, artwork packages, event materials, operational procedures or software
distributions. Include editable files when they are part of the agreed delivery.

This folder is optional. When results live in another tool, storage location or
the physical world, link to them from [delivery](../docs/delivery.md).

Organize files around what people receive and identify the intended version
when alternatives could cause confusion. Keep the working materials used to
produce them in [src/](../src/README.md), with links where helpful.

Use [delivery](../docs/delivery.md) to explain contents, usage, access and
handover. Keep prepared, checked, accepted and delivered states clear when they
differ. Link to relevant [checks](../tests/README.md) and
[evidence](../evidence/README.md) from that record.
