# Delivery and handover

## Use and handover

Start with the [README](../README.md), then read the [architecture proposal](proposal.md). The [project records](README.md) make scope, status and unresolved decisions discoverable.

The proposal embeds three PNG diagrams so its visuals work in Markdown viewers without a Mermaid renderer. [HTML sources](../src/README.md) support editing. They load fonts from Google Fonts when opened in a browser; the PNGs already contain the rendered text.

## Delivery acceptance and remaining work

For the current milestone, delivery is the public repository containing the intended documentation commit. [Publication checks](../tests/README.md#documentation-publication-checks) cover inventory, fidelity, links/assets, public-content inspection and Git/visibility verification.

This is a documentation deliverable. There is no executable routing service, installed product or demonstrated cost/quality result. [Current work](current-work.md) identifies the proposed next milestone and its dependencies.

## Outcomes and learning

The intended benefit remains lower conversation-level spending within an agreed quality range. Only the proposal's later evaluations can assess it. Any commissioned study must specify its owner, acceptance criteria, timing and evidence; no ongoing operational or follow-up obligations have been assigned by this publication.
